# IEEE Spider Drone

## Setup

Preferences > Additional boards manager URLs:

```
https://raw.githubusercontent.com/pdcook/nRFMicro-Arduino-Core/main/package_nRFMicro_index.json
https://files.seeedstudio.com/arduino/package_seeeduino_boards_index.json
```

Tools > Board Manager > Search and install 'nRFMicro Boards'

Navigate to `C:\Users\{USER}\AppData\Local\Arduino15\packages`, rename folder `nRFMicro-like Boards` to `nRFMicro`

Tools > Board > 'nRFMicro-Style Boards' > Pick one
